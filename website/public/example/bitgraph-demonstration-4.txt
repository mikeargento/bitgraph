A BitGraph demonstration.

This file came after two things.

1. A position commitment
Before this file was made, an unused position opened up in BitGraph's sequence. At that moment, BitGraph's hardware generated a new random number, too large to ever be guessed, and tied it to that position. From the two, BitGraph worked out a code called a position commitment. That code had never existed before, anywhere in the universe, and now it's part of this file:
8jaht3ou1KKqYe_dAW5bPd-J2qlyN-wh21ZeAbJyxlU
Then the file was committed to that position, and the position was consumed. It can never hold anything else.

2. An Ethereum block
Ethereum is a public blockchain kept by thousands of computers worldwide. A new block is added about every 12 seconds. Right after the position for this BitGraph opened, another BitGraph recorded the newest Ethereum block:
https://bitgraph.ing/proof/elUx4aE71QFgXIxge_Xd9TycF9KahO15Y1TJzfk5ctA

So this file could not have been written before its position commitment existed, or before that Ethereum block existed. Change a single character and it no longer matches.

And one thing came after it.

3. A Base block
Seconds after this file was committed, BitGraph wrote its fingerprint, folded in with any others from those seconds, into a transaction on Base, another public blockchain. The block that holds it shows this file existed by then. That can't be written inside the file itself, so it travels beside it: the proof page shows it, and the ceiling file comes with the download.

The Ethereum block is this file's floor, and the Base block is its ceiling. It was made between the two, and anyone can check both without asking BitGraph.

This is a text file, but it could be any record written around its position commitment, for example an AI agent's log as the agent runs.

It doesn't prove this file is true, or who wrote it.

BitGraph doesn't stop anyone from lying between 1955 and 1985. It stops anyone from going back to 1955 with the Grays Sports Almanac.
